<TT>˗ˏˋ ★ ˎˊ˗RULES OF ENGAGEMENT</TT>
1. **Take What You Get:** Click **New Repository**, accept the **first** auto-generated default name GitHub offers. No refreshing.
2. **Make It Fit:** The project *must* match the codename's vibe, acronym, or literal meaning (e.g., `psychic-garbanzo` could be an RF signal sniffer that predicts packet bursts).
3. **Zero Bloat:** No giant frameworks, no pointless dependencies. If it can be done in C, Python, Bash, or raw solder, keep it lean.
